The primary clickable control for every action on the site — donating, adopting, sponsoring, filtering, form submission.

```jsx
<Button variant="cta" icon="heart" wag>Dona hoy</Button>
<Button variant="secondary">Ver más</Button>
```

Variants: `primary` (blue, default nav/site actions), `cta` (terracotta, donate/adopt — the button people should notice), `sponsor` (amber, apadrinar), `secondary` (outlined blue), `ghost` (text-only). Sizes: `sm` `md` `lg`. Set `wag` on donate/adopt CTAs for the brief's tail-wag microinteraction — the icon gently rotates on hover.
