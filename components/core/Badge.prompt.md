Small pill used for dog attributes and states: "Adoptado", "Energía alta", "Compatible con niños", filter chips.

```jsx

```

Tones: `success` (sage, adopted/health-cleared), `info` (blue, neutral facts), `warning` (amber, needs attention), `neutral` (gray, default tags).
